# Kitdox public site

Static GitHub Pages site with English/Turkish landing, privacy and support pages.

- `index.html`: homepage
- `privacy.html`: bilingual pre-launch privacy policy
- `support.html`: bilingual support page
- `styles.css`, `site.js`: presentation and language selection

## Deployment
Upload files to the root of the `main` branch in the public `kitdox-site` repo, then enable GitHub Pages: `Settings > Pages > Deploy from a branch > main > /(root)`.

**Before shipping**: Review the final product name, App Store Connect disclosure requirements, official Apple privacy report, Google Mobile Ads/UMP privacy disclosures and the unresolved RD-06 privacy release gate. Production ads must remain disabled until that review is completed. The website does not automatically update application-side privacy disclosures.
